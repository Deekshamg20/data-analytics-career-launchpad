Low-Code Skill Matrix

High-ROI tools replacing traditional algorithmic software engineering rounds.

Essential

Advanced SQL

Core data extraction, transformation, and business aggregations.

  • JOINs (INNER, LEFT, CROSS)
  • Window Functions (ROW_NUMBER, DENSE_RANK, LEAD/LAG)
  • CTEs and subqueries for data manipulation
  • Aggregation with GROUP BY, HAVING, and CASE WHEN
Benchmark: Solve intermediate HackerRank/StrataScratch SQL problems.
Essential

Power BI / Tableau

Executive dash-boarding, semantic modeling, and KPI tracking.

  • Star-schema data modeling (Facts vs. Dimensions)
  • DAX basics: CALCULATE, RELATED, SUMX, Time Intelligence
  • Row-Level Security (RLS) & Drill-through navigation
  • UX best practices for C-suite executive consumption
Benchmark: Build 2 interactive dashboards linked to public datasets.
High Value

Applied Business Analytics

Translating raw data into measurable operational decisions.

  • Cohort analysis & retention curve modeling
  • Funnel analysis for SaaS and E-commerce
  • A/B test significance testing basics
  • Spreadsheet mastery: INDEX/MATCH, XLOOKUP, Pivot Tables
Benchmark: Write a 1-page business brief identifying revenue leakage.

4-Week Structured Action Plan

2 to 3 hours per day dedicated to skill acquisition, asset creation, and direct pitching.

Week 01 2.5 hrs/day

SQL Mastery & Schema Modeling

Ditch theory books. Work straight inside PostgreSQL or BigQuery on realistic sales data.

  1. Days 1–3: Master aggregate queries, multi-table joins, and temporal extraction.
  2. Days 4–5: Build fluency with CTEs, rolling sums, and ranking window functions.
  3. Days 6–7: Complete 20 real interview queries on StrataScratch/LeetCode Data track.
Week 02 3 hrs/day

Power BI Portfolio Project #1

End-to-end dashboard focusing on Customer Churn or Supply Chain bottlenecks.

  1. Days 8–9: Source raw dataset (Kaggle/data.gov), normalize into Star Schema.
  2. Days 10–12: Write DAX measures for Year-over-Year (YoY) growth and churn rates.
  3. Days 13–14: Design accessible UI with custom cards, tooltips, and slicers.
Week 03 2 hrs/day

Case Study #2 & GitHub Documentation

Translate visual dashboards into readable GitHub repositories and interactive web links.

  1. Days 15–17: Create SQL pipeline demonstrating ETL, cleanup, and aggregation.
  2. Days 18–19: Publish Power BI to web or record a 90-second Loom dashboard walkthrough.
  3. Days 20–21: Write clean README documentation with context, findings, and business recommendations.
Week 04 3 hrs/day

Direct Outreach & Interview Sprints

Target mid-sized firms, startup founders, and agency leads with tailored work samples.

  1. Days 22–24: Identify 30 mid-sized agencies and 15 incubators; map founder emails via Hunter/Apollo.
  2. Days 25–26: Send 8 personalized cold emails/LinkedIn notes daily with your project link attached.
  3. Days 27–28: Follow up on open conversations; prepare responses for take-home data challenges.
